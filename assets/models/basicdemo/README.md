# Teacher basicdemo OBJ models

Copied unchanged from `basicdemo.zip`, `basicdemo/objmesh/assets/`:

- `tetra.obj`: tetrahedron.
- `teapot.obj`: Utah teapot.
- `suzanne.obj`: Blender monkey head.
- `bunny.obj`: Stanford Bunny.

Original model attribution and usage terms are preserved in `CREDITS.txt`.
Keep that file when redistributing these assets.

In the app, expand **Import OBJ**, browse to an OBJ in this directory, and import it.
The importer centers each model and fits it to a two-unit box. Use **Focus selected**
to move the camera to the imported object. Models are not automatically added to the scene.

The build copies this directory to `assets/models/basicdemo/` beside the executable.
These models do not require the Python `cglibs` library.
